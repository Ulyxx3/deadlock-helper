Installation & Lancement rapide (Windows)

1. Cloner et installer

git clone https://github.com/Ulyxx3/deadlock-helper.git
cd deadlock-helper
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
cd frontend && npm install && npm run build && cd ..

2. Lancer le Companion

.\.venv\Scripts\python.exe -m backend.main --server

Ouvre ensuite http://127.0.0.1:8765 sur ton second écran, entre ton pseudo une fois et appuie sur TAB en jeu.

Questions fréquentes

Est-ce 100 % sans risque vis-à-vis du VAC ?

Oui. Aucune lecture mémoire (RPM), aucune DLL injectée et aucun fichier du jeu modifié. L'application analyse uniquement les pixels de ton écran quand tu appuies sur TAB.

Ça fonctionne avec des skins DeadlockModManager ?

Oui : la détection des héros ne dépend pas des portraits (qui peuvent être moddés), mais de l'OCR du nom de héros sous la carte avec correction fuzzy FR/EN.

Comment aligner les zones sur un autre format d'écran ?

Lance --image capture.png --dump-rois data/debug_captures pour visualiser les boîtes générées et ajuste les coordonnées normalisées dans backend/config/rois.json.

Pourquoi Valve GSI n'est-il pas utilisé ?

Valve n'a pas encore publié de Game State Integration pour Deadlock. Le code inclut déjà une interface abstraite MatchDataProvider prête pour le jour où il sera disponible.
